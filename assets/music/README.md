# Music folder

Put **YouTube Audio Library** downloads here (from [YouTube Studio](https://studio.youtube.com) → Audio library).

- Prefer formats your mixer supports (often `.mp3` or `.wav`).
- Keep filenames readable; a future step may pick a track by name or config.
- Note each track’s **License type** and **Attribution** in Studio and carry attribution into your published description when required.

These files are usually large binaries; add them locally and avoid committing them to git unless your team explicitly wants shared assets.
